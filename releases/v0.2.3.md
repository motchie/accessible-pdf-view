A document's title is no longer read twice, heading counts match the headings you can move to, and the libraries underneath are current. The extension now declares the browsers it needs.

## What changes for a reader

- **The title is read once.** The Reader shows the PDF's title as the page heading and drops a first heading that repeats it. Word tags its Title-style paragraph as a heading, and in Japanese the two did not match: extraction drops the space between Japanese characters, and the title metadata keeps it. So 「検証用文書 その1」 was read again as 「検証用文書その1」. They are now compared the same way.
- **Heading counts are the headings you can move to.** The structure picker's counts, and the notice that says another reading has headings, used to count the title heading the Reader does not show. A reading whose only heading was the title was offered as having one. The Markdown view also no longer repeats the title under its own `#`.
- **A tagged document whose only heading tag is its title now gets the combined reading** (構造タグ＋推測した見出し), as one with no heading tags does. Before, Word's Title-style heading made it look as if the author had tagged headings.
- **Chrome 147 or later is required** (Edge 147; Firefox 144, whose build is not published yet). The bundled PDF.js calls newer JavaScript without checking for it first, and every earlier release already depended on it. Where one of those is missing, embedded fonts fail to load and text is read from a substitute font: seen in testing, where the same method was missing, though not run in an old browser. The Chrome Web Store will now say the extension is not compatible there, instead of installing something that may misread documents. (#23)

## What does not change

- **PDF.js 6.4.299** (was 6.3.289) and **pdf-inspector 1.25.2** (was 1.25.0), still with this project's fix for Japanese and Chinese text in fonts without a ToUnicode map. Measured on fourteen documents, each opened with every reading preference, what the Reader shows is the same as with the previous versions.
- The extension is about 0.45 MB smaller. PDF.js's module for running a PDF's own JavaScript was being copied in, and nothing used it.

## Not changed yet

- A tagged figure under 24pt on a side is still not shown as an image. Where to draw that line is #15.
- An author's alternative text is still read by screen readers but not drawn on screen when the image is shown. Every way of drawing it would cost something we decided not to pay: hiding visible text from assistive technology, or turning a described image decorative. #17 is closed for now with the reasons.

## Under the hood

- **Hand-written expectations for what screen readers get.** A Word document written for this project, exported as a tagged PDF, is now in the repository with an outline of what the Reader should expose: headings, lists, table headers, figures, and what must be absent. CI checks it on every change. That check found the title bug above.
- `THIRD_PARTY_NOTICES.md` named PDF.js 6.2.108 while 6.3.289 shipped. It is correct now, lists the packages bundled with each component, and a test fails if it drifts from the lockfile again.

## 日本語

文書のタイトルを二重に読まなくなりました。見出しの件数は、実際に移動できる見出しの数と一致するようになりました。内部で使うライブラリも最新にしています。また、動作に必要なブラウザを明示しました。

- **タイトルを 1 回だけ読みます。** Reader は PDF のタイトルをページの見出しとして表示し、本文の先頭にある同じ見出しは省きます。Word は「表題」スタイルの段落を見出しとしてタグ付けしますが、日本語ではこの 2 つが一致しませんでした。本文からは日本語の文字間の空白が除かれ、タイトルの情報には空白が残っているためです。このため「検証用文書 その1」が「検証用文書その1」としてもう一度読まれていました。今は同じ方法で比べます。
- **見出しの件数が、移動できる見出しの数になりました。** 構造の読み取り方の選択欄の件数と、別の読み取り方には見出しがあることを知らせるメッセージは、Reader が表示しないタイトルの見出しまで数えていました。タイトルだけが見出しの読み取り方が、見出し 1 件として案内されることがありました。Markdown 表示でも、`#` のタイトルの下に同じタイトルを繰り返さなくなりました。
- **見出しのタグがタイトルだけのタグ付き PDF にも、「構造タグ＋推測した見出し」の読み取りを用意します。** 見出しのタグがない文書と同じ扱いです。これまでは Word の「表題」の見出しがあるだけで、作成者が見出しを付けた文書として扱っていました。
- **Chrome 147 以降が必要になりました**（Edge 147。Firefox 144。Firefox 版はまだ公開していません）。同梱の PDF.js は新しい JavaScript の機能を、あるかどうか確かめずに使います。これまでのリリースもすべてそうでした。その機能がない環境では、埋め込みフォントの読み込みに失敗し、代わりのフォントから文字を読みます。同じ機能がないテスト環境で確認したもので、古いブラウザでは試していません。今後は Chrome ウェブストアが「互換性がない」と表示し、文書を誤って読むおそれのある状態でインストールされることはなくなります。（#23）

変わらないこと：

- **PDF.js 6.4.299**（これまでは 6.3.289）と **pdf-inspector 1.25.2**（これまでは 1.25.0）にしました。ToUnicode のないフォントの日本語・中国語を読むための修正は、引き続き当てています。14 の文書をすべての読み取り方で開いて比べ、表示される内容が以前と同じであることを確かめています。
- 拡張機能が約 0.45 MB 小さくなりました。PDF に含まれる JavaScript を実行するための PDF.js のモジュールが、使われないまま同梱されていました。

まだ変えていないこと：

- 縦か横が 24pt に満たないタグ付きの図は、今も画像を表示しません。基準の見直しは #15 で検討します。
